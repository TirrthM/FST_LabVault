## 📊 Dataset Volume & Distribution

| Entity Model | Seed Count | Description & Relational Integrity |
| :--- | :---: | :--- |
| **Users** | 32 | 7 Core deterministic users (Admin, 2 Managers, 2 Techs, 2 Students) + 25 weighted random academic profiles. |
| **Labs** | 6 | Specialized departmental facilities (Robotics, Microscopy, VLSI, Materials, Chemistry, Bioengineering). Each has an assigned Lab Manager. |
| **Equipment** | ~65–70 | High-value scientific assets (FE-SEM, HPLC, FTIR, Oscilloscopes, qPCR). 10–12 items per lab with realistic serial numbers and asset IDs. |
| **Borrow Requests** | 90 | Complete spectrum of lifecycle states (`REQUESTED`, `APPROVED`, `BORROWED`, `RETURNED`, `INSPECTED`, `REJECTED`). |
| **Maintenance Tickets** | 35 | Service work orders (`OPEN`, `ASSIGNED`, `IN_REPAIR`, `TESTING`, `RESOLVED`) across 4 priority tiers. |
| **Work Logs** | 60+ | Diagnostic work entries linked to tickets, recording technician hours, notes, and replaced components. |
| **Calibration Records** | 35 | Metrology records with NIST standards, certificate numbers, and calibration currency (`CALIBRATED`, `DUE_SOON`, `OVERDUE`). |
| **Audit Logs** | 130 | Immutable chain-of-custody log stream recording entity actions, actors, IP addresses, and JSON payloads. |
| **Email Events** | 25 | Resend delivery events (`SENT`, `DELIVERED`, `OPENED`, `BOUNCED`). |

## ⚙️ Package Scripts & Database Workflow

The following scripts are configured in [`package.json`](file:///d:/LabVault/package.json):

### 1. Initial Setup & Prisma Generation
```bash
# Generate the Prisma Client types
npm run db:generate
# (or: npx prisma generate)
```

### 2. Apply Migrations to PostgreSQL
```bash
# Run migrations in development mode
npm run db:migrate
# (or: npx prisma migrate dev --name init)
```

### 3. Seed Database with Faker.js
```bash
# Execute seed script
npm run db:seed
# (or: npx tsx prisma/seed.ts)
```

### 4. Database Reset (Wipe & Re-seed)
```bash
# Force reset database schema and automatically trigger prisma.seed
npm run db:reset
# (or: npx prisma migrate reset --force)
```

### 5. Inspect Data via Prisma Studio GUI
```bash
# Launch interactive web visualizer on http://localhost:5555
npx prisma studio
```

## 🔒 Determinism & Reproducibility

To guarantee reproducible test runs during grading and QA:
- `prisma/seed.ts` calls `faker.seed(123456)` at initial execution.
- Running `npm run db:seed` multiple times produces predictable relational associations across all entities.
- Core demonstration users (`usr_student_01`, `usr_tech_01`, `usr_mgr_01`, `usr_admin_01`) maintain static IDs and credentials matching the frontend role switcher.
